## 📌 Project Overview
This project is a complete corporate website developed as part of an internship assignment. It showcases a professional agency presence with service offerings, portfolio display, and an integrated meeting booking system.
The application also includes user authentication and real-time data storage using Firebase.

---

## ✨ Features

### 🎯 Core Functionality
- Fully responsive modern UI
- Smooth navigation and structured layout
- Interactive animations using GSAP
- Functional contact form
- Meeting/appointment booking system
- Firebase Authentication (Login/Signup)
- Firestore database integration for storing booking data

---

### 🧩 Pages Implemented
- Home
- About Us
- Services
- Portfolio
- Contact Page
- Booking Page
- Blog

## 🔐 Authentication System
- User Signup & Login functionality
- Firebase Authentication used for secure access
- Enables user-specific booking interactions

---

## 📅 Booking System
- Users can schedule appointments via the booking interface
- Only authenticated users can book a meeting
- Booking data is stored in Firebase Firestore
- Designed to simulate a real-world client scheduling system
